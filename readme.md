This project focuses on identifying trends within the Parfumo database given by TidyTuesday.
This database has 59,300 or so entries. 

My research questions center on scent trends based on the release year and accords of perfumes
given by the dataset, as well as how certain accords tend to associate with each other. 

Please note that for about the first third of working on this project I didn't really know how to use my repository, so my first couple commits are very large as I was copy-pasting from a local file. I promise that I was working on this for more than just this week, I just had beef with github. 

data-exploration holds most of my work. This is where I just played around with everything. I've been lucky enough that there was a cleaning script already included with this dataset, which I went ahead and used. The first several lines of code in that file are testing how much data I'm left with after dropping all NA values of different columns, and this is how I landed on a combination of release year and accords because it had the most useable data. I also filtered by release year, because I found entries of perfumes from the 1800s. I don't even know how that's possible. 

final-graphs holds all of my cleaned-up work after deciding what to focus on and which graphs are good enough, as well as making some different versions of those graphs.

final-ppt.qmd was supposed to be my Quarto presentation, which I wanted to do to challenge myself, but after seeing all the technical issues in class over the past week I've decided to go with a regular powerpoint. I let it stay as a testiment to my intentions.
